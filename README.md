## 💡 比赛当天最佳运行架构：「本地电脑控大屏 + GitHub 供手机看成绩」

这个组合是学校运动会现场**最稳妥、最实用**的架构：

1. **记录台电脑端（现场大屏 0 延迟、不怕操场断网）**：
   - 在记录台电脑上打开这三个页面（建议在项目文件夹内打开终端运行 `py -m http.server 8080`，访问 `http://localhost:8080/admin.html` 与 `tv-display.html`）。
   - 记录台主屏操作 `admin.html` 录入成绩，点击 **「↗ 新窗投屏」** 把 `tv-display.html` 拖到 HDMI 连接的电视机 / LED 大屏幕并全屏（`F11`）。
   - 两页通过浏览器本地 `BroadcastChannel` 通信，**断网也能毫秒级秒切画面、放破纪录礼花与音效**。

2. **师生手机端（通过 GitHub Pages 浏览最新成绩）**：
   - 手机扫码打开 `https://felixyu9722.github.io/sinmin-sports-2026/`。
   - **两种云端同步方式任选其一**：
     - **方案 A（最简 · GitHub Pages 直推）**：在记录台电脑 `admin.html` →「☁️ 云端同步」中填入仓库 `felixyu9722/sinmin-sports-2026` 与本地 GitHub Token，勾选「推送大屏时自动同步到 GitHub 手机端」。每次电脑点推送大屏，全校手机端 20 秒内自动刷新出最新成绩与积分榜！
     - **方案 B（Google Sheets CSV 实时同步）**：将决赛成绩表用 Google Sheets「发布到网络 → CSV」，在网页「☁️ Google Sheets 同步」填入链接即可同步。

## ✨ 已集成的新民中学竞赛章程自动化功能

- **四色队伍与初中/高中分组**：红（1）、黄（2）、蓝（3）、青（4）；甲组（高中，男甲=1 / 女甲=4，**白色号码布**）、乙组（初中，男乙=2 / 女乙=5，**黄色号码布**）。
- **4 位编号智能解析（章程 13、14 条）**：输入 `1101` 自动识别为红队男甲并渲染仿真白色号码布。
- **预赛晋级（Q / q）与决赛道次自动编排（章程 10.1.2 ~ 10.1.3）**：
  - 常规 4 道：两组各取第 1 名 `Q` + 择优 2 名 `q`，决赛自动排入 **第 3、2、1、4 道**。
  - 60 米 6 道：两组各取第 1 名 `Q` + 择优 4 名 `q`，决赛自动排入 **第 4、3、2、5、1、6 道**。
- **计分与并列平分（章程 10.2 ~ 10.4）**：个人决赛 `7-5-3-2-1`，团体决赛 `10-7-5-3-1`；同成绩自动平均分配所占名次分数；田赛支持 3 次试跳/试投并自动比对次佳成绩。
- **缺席跨项目失格预警（章程 15.1）**：若选手在任一项目被标为 `DNS`，后续所有项目自动弹出红底失格警告。
- **奖杯与实体奖牌颁发细节（章程 9 & 10.5）**：自动统计全场总冠军杯（1座）、最佳精神奖杯（1座）、四组最佳运动员奖杯（4座，个人金牌最多者、同数共享），以及实体奖牌实领数量（个人 1 面 / 接力 5 面 / 拔河与大队接力 8 面）。
- **Excel 零后端读写**：支持 `.xlsx` / `.csv` 拖拽批量导入、下载标准报名模板、赛后一键导出含 5 张统计工作表的完整归档 `.xlsx`。

## 📁 文件结构

- `index.html` — 公开成绩查询与四色总积分榜（手机/电脑）
- `tv-display.html` — 决赛现场大屏幕投影页（7 大模式、手动切屏、自动轮播、礼花与跑马灯）
- `admin.html` — 现场成绩录入与导播控制台（Excel 导入、PiP 预览、一键推送大屏、打印检录单）
- `css/style.css` — 深色广播级科技感主题、号码布样式与 `Animate.css` 动效
- `js/core.js` — 新民中学章程核心规则引擎、SheetJS 读写、跨标签页与云端同步模块
- `data/live-state.json` — 云端实时赛事数据快照（供手机端 `index.html` 自动拉取）
- `Sin Min Logo.png` — 新民中学校徽
